# ヴォーカル＆コード譜の標準形式 — Web・論文網羅調査（2026-07-28）

**目的:** コード譜出力（#150で可読化済み）を世の中の標準「ヴォーカル＆コード譜」に合わせるための仕様根拠。X調査は [vocal-chord-format-grok-x.md](vocal-chord-format-grok-x.md)。
**調査手段:** deep-researchワークフロー（5角度×並列Web検索→22ソース精読→107クレーム抽出→上位25件を3票敵対的検証）。以下は生き残った検証済み知見13件（票数付き）。

## 1. 結論（3ソース系統が完全一致）

**「ヴォーカル＆コード譜」の標準形式 = リードシート（日本の商品名は「メロディ譜」）:
五線譜1段のボーカルメロディ＋五線上部のコードネーム＋五線下部の歌詞。**

- 日本業界（ヤマハぷりんと楽譜・@ELISE）〔3-0×2〕: 「メロディ譜=1段譜＋歌詞＋コードネーム（カラオケ・弾き語り用途）」。シンコーの「ヴォーカル&コード」・メロ譜・リードシートは同形式の別名。
- 分岐点は「五線メロディ」と「伴奏譜」の有無〔3-0×2〕: 弾き語り譜=伴奏パート付き / メロディ譜=1段譜のみ / **コード譜=五線なし・歌詞＋コード進行のみ（U-FRET型）**。→ 当エンジンの出力は「メロディ譜」カテゴリを名乗るのが正しく、「弾き語り譜」「コード譜」を名乗ると誤解を生む。
- 学術（ISMIR 2009 Weil / ISMIR 2022 Sheet Sage）・教育（Berklee）・実装（LilyPond/MuseScore）・百科事典で同一レイアウト〔3-0×4〕。

## 2. 構成要素マトリクス（検証済み）

| 区分 | 要素 |
|---|---|
| **必須** | 五線メロディ・コードシンボル・音部記号・調号・拍子 |
| **準必須** | 歌詞（歌モノ）・テンポ |
| **任意** | スタイル指示・リハーサルマーク/セクション名（Intro/Verse/Chorus）・リピート/コーダ・ソロ区間のスラッシュ記法 |
| **意図的に省略** | ダイナミクス・アーティキュレーション・コードボイシング・ベースライン・伴奏詳細（演奏者/アレンジャーに委ねる）〔medium〕 |

- ヤマハ公式ガイド〔3-0〕:「コードや歌詞、ピアノ伴奏譜は必ず記載されているわけではない」→ 必須/任意マトリクスを設ける業界慣行の直接根拠。

## 3. 記法・刻印の実装基準

- **コードシンボル構文**〔3-0×2〕: ルート文字＋品質サフィックス(m/aug/dim)＋7th＋括弧テンション C7(#11)＋スラッシュベース C7/E。ルート綴りはロケール依存（Standard/German/Solfeggio/French — MuseScoreは5方式実装）で世界単一標準は無い。
- **省略表記のリファレンス実装**〔3-0〕: LilyPond既定 = Ignatzekジャズ記法（メジャー=ルートのみ「C」、マイナー=「Cm」）。
- **歌詞タイポグラフィ**〔3-0〕: 音節間ハイフン・メリスマのワードエクステンション・フレーズマーク。MusicXML syllabic/extend 要素に対応。
- **レイヤー分離アーキテクチャ**〔3-0×3〕: コードネームはメロディ五線と独立したレイヤー（LilyPond ChordNamesコンテキスト / MuseScoreは五線上部アタッチ）。エンジンもメロディ・コード・歌詞を独立ストリームで持ち刻印時に合成する設計が妥当。

## 4. 学術パイプライン要件（audio-to-lead-sheet）

- 必須コンポーネント〔3-0〕: メロディ採譜＋コード認識＋**キー推定＋拍子推定**。Sheet Sage (ISMIR 2022) はKrumhansl-Schmucklerキー推定＋madmom拍検出＋LilyPond刻印（固定キー・固定拍子の限定つき）。
- 可読レンダリング基準〔3-0〕: 音符は8分音符グリッド量子化が良好なトレードオフ（Weil 2009。後続は16分も使用・体系的比較は無し）。音名/コード名のスペリングは**推定キー前提で五度圏距離最小化**が標準。
- 最前線〔3-0〕: arXiv:2502.12438 (2025) — ポリフォニック音源から歌唱メロディの onset/offset/pitch/note value を統合認識する end-to-end 拡張ノートレベル採譜（別段の量子化ステージなし）。

## 5. 当エンジンへのギャップ分析

| 標準要素 | 現状 | ギャップ |
|---|---|---|
| 五線メロディ（vocals分離→mono採譜→Verovio刻印） | ✅ あり | — |
| コードネーム（クロマ相関推定） | ✅ あり（別PDF） | **五線上部への合成が未実装**（現在は2枚分離） |
| 歌詞 | ❌ なし | **新規コンポーネント**（歌声ASR＋歌詞アライメント）が必要 |
| 調号・拍子・テンポ | ✅ あり | — |
| セクションマーク・リピート | ❌ なし | 任意要素（後回し可） |
| 押さえ図 | オプトイン化済み(#150) | 標準では非掲載 → 現仕様が正 |

**含意:** 「ヴォーカル＆コード譜」を名乗るなら、最終形は**1枚のリードシート**（五線メロ＋上コード＋下歌詞）。現行の2枚セット（五線譜＋コード譜グリッド）は中間形。実装順は (1)コードネームの五線上部合成（MusicXML harmony要素 or 刻印層で合成・レイヤー分離設計）→ (2)歌詞（ASR＋アライメント、別R&D）。
