## 2. 失敗モード分類

```
┌─────────────────────────────────────────────────────────┐
│ 失敗モードマップ（投稿から帰納）                          │
├──────────────────┬──────────────────────────────────────┤
│ M1 倍音ゴースト  │ 倍音・ノイズ・弦鳴りを「実音」としてMIDI化 │
│ M2 単音化        │ ポリフォニー未対応／和音が1線に潰れる     │
│ M3 過密和音      │ スペクトル上の全ピークを和音構成音に採用   │
│ M4 コード誤推定  │ add9/aug等の誤検出、または単純化しすぎ   │
│ M5 音色依存劣化  │ 歪みGt・低音金管・リバーブで精度崩壊     │
│ M6 パワーコード化│ 3度が埋もれ root+5th だけになる（人力/AI）│
│ M7 検証不能      │ 精度が高すぎてパート境界が読めない        │
│ M8 隠蔽          │ 自動伴奏等で誤りに気づかない              │
│ M9 処理破綻      │ 変換不能・待ちすぎ・編集すると崩壊        │
└──────────────────┴──────────────────────────────────────┘
```

| モード | 典型ツール | 物理/アルゴリズム要因（投稿から読み取れる） |
|--------|-----------|---------------------------------------------|
| **M1 倍音ゴースト** | WaveTone MIDI、Melodyne、AI採譜一般 | フーリエ/ピッチ追跡が倍音列を別ノート扱い |
| **M2 単音化** | Edison系、一部簡易AI | モノフォニック前提のピッチ検出 |
| **M3 過密和音** | WaveTone「全部鳴らす」運用 | スペクトル表示を譜面に直写しすぎ |
| **M4 コード誤推定** | WaveToneコード解析、スコアメーカー | 倍音由来の9th/7thや伴奏補正の誤誘導 |
| **M5 音色依存** | RipX、NN採譜 | 歪み=倍音密集、リバーブ=時間 smear |
| **M6 パワーコード** | 人力耳コピ中心（AIでも同型が予想） | 3度が弱く、root/5thだけ目立つミックス |
| **M7 検証不能** | Basic Pitch高精度側 | 過剰検出で「演奏意図」が読めない |
| **M8 隠蔽** | スコアメーカー自動伴奏 | プレビューが誤りをマスク |
| **M9 処理破綻** | Basic Pitch待ち、Melodyne和音編集 | 負荷・素材難易度・編集耐性 |

### ツール別の「刺さり方」

| ツール | 投稿上の失敗の出方 | 相対評価の傾向 |
|--------|-------------------|----------------|
| **WaveTone** | MIDIの倍音全吐き、コード解析の信憑性、全部見る→ミス | 視覚補助・和音の**目安**には定評。**出力をそのまま信じてはいけない** |
| **Basic Pitch** | 精度高すぎて分離不能、遅い、曲によっては変換失敗 | 単体精度はWaveToneより上という声もあるが**運用性・可読性**に不満 |
| **Melodyne** | 倍音拾い過ぎでハモ化、編集で崩壊、和音解析で悪化 | ボーカル補正は強いが**「採譜ソース」としての和音解析は地雷**報告あり |
| **かんたん/AI系** | 和音5個化、ガタガタ譜面、ギター倍音ゴースト | デモは良くても**実演奏用譜面は未達**というプロ側の声 |

## 4. 投稿密度の所感

- **最も具体的な失敗談**は **WaveToneの「倍音全吐きMIDI」**（@lostresistance4）と **Melodyneの倍音ハモ化**（@saxcova）、**ギターAI採譜の倍音誤音符**（@VitaminGui2044）。
- **「和音→単音」**はアプリ名付きだと Edison/簡易検出系が多く、WaveToneは逆に **「単音不足」より「音の過多」** 側の苦情が多い。
- **「パワーコードが取れない」**をアプリ名付きで直接罵倒する投稿は少なく、多いのは  
  - 人力で **全部パワーコードになってしまう**（@Ozintheworld916）  
  - 自動系は **単音/パワーコード程度なら将来いけるが歪みGtは無理**（@GkmGuitar, @IT7C）  
  という形。
- Basic Pitchは日本語圏では **「精度 vs 待ち vs 可読性」** の運用不満が中心で、「倍音」という語での炎上は少なめ。

## 5. 実務メモ（失敗モード対応の最短手順）

1. **フルミックス直投げしない** → ステム（少なくとも Gt / Bass / Keys）  
2. **MIDIを「正解」にしない** → WaveToneはスペクトル確認用、コード名は要検算  
3. **倍音候補の除去ルール**を持つ（オクターブ上・完全5度上を疑う、発音アタック直後だけ強い線はゴースト候補）  
4. **3度の有無**でメジャー/マイナー/パワーコードを人間が最終判定  
5. プレビューは **伴奏なしの素の和音再生**で誤検知を炙る  

必要なら、上記投稿IDからスレを深掘りする／英語圏の Basic Pitch・Melodyne 失敗談も同じ分類軸で横断比較できます。
