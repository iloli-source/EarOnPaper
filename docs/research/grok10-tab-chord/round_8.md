## 二、问题本质（中 + 日对照）

**中文**  
和弦识别 = 多音高（multi-F0）问题。每个「真音符」在频谱上是一串谐波 \(f, 2f, 3f, \ldots\)。当多个音同时响时：  
- 一音的 \(2f\) 可能落在另一音的 \(f'\) 上（**谐波重叠 / harmonic collision**）  
- 强泛音可能比弱基音还高（**假根音 / octave error**）  
- 缺失基音时，人耳与算法都会用谐波反推 F0（**missing fundamental**）——既是能力，也是误判源  

**日本語**  
和音認識は multipitch 問題。各実音は倍音列を持つ。  
- 他音の倍音とピークが重なると **誤って余分な音を検出**  
- 倍音ピークが基音より強いと **オクターブ誤検出**  
- 基音が弱くても倍音から F0 を補完（**ミッシングファンダメンタル**）し、偽の構成音を生む  

X 上实务吐槽的典型场景：**电吉他失真 backing、弦乐/合唱 dense 倍音**（帖 1、2）。

## 三、技术方法总结（帖子观点 + MIR 共识）

### 1. 谐波模板 / 谐波求和（Harmonic template / salience）

| 思路 | 对应帖 | 做法 |
|------|--------|------|
| 用谐波族投票 F0 | 4, 7–10 | 对候选 \(f\) 在 \(2f,3f,\ldots\) 上累加能量；**salience 最高者为基音**，而非「频谱峰最高」 |
| GCD 型补全 | 8 | 观测到的谐波频率集合取 **GCD ≈ 基频**（离散化到音分后） |
| 防「最响峰 = 音高」 | 10 | 禁止把 max dB 峰直接当 note；要求 **谐波一致性** |

### 2. 谐波去重 / 从属关系（Harmonic pruning）

- 若候选音 \(g \approx k \cdot f\)（\(k=2,3,4\ldots\)）且 \(f\) 的 salience 更高 → **判 \(g\) 为 \(f\) 的倍音，不当独立和弦音**  
- 帖 3、6：落在同一倍音列上的峰，**不应拆成多个和音构成音**  
- 帖 11：完全五度（≈第 3 倍音）特别容易被「溶掉」或反过来被误增  

### 3. Missing fundamental 显式建模

- 帖 4、7、9：基音峰很弱时仍应输出该 F0  
- 实务：YIN/pYIN、cepstrum、harmonic product spectrum、spectral autocorrelation  
- 风险：和弦中 **一音的倍音组合** 可能「假造」另一个不存在的根（尤其低音区）  

### 4. 先分离再识别（Separate-then-transcribe）

- 帖 1 串、15–16：混合态下倍音缠死 → **stem 分离（MSS）后各自 monophonic pitch**  
- 仍失败场景：单轨内多音（钢琴和弦、失真吉他和弦）——分离帮不了轨内 multipitch  

### 5. 和弦先验 / 约束解码（Musical language model）

- 帖 1：电吉他难估时 **「从曲のコード反推 pitch」**  
- 帖 2：复杂和声（sus/add9/on）+ 倍音 → 纯频谱不够，需要 **chord lexicon + 调性/进行先验**  
- 典型流水线：multi-F0 候选 → 音级 chroma → HMM/CRF/Transformer 和弦序列  

### 6. 音色/包络线索（不仅靠稳态频谱）

- 真音符：**起振（attack）瞬间高次倍音强，之后衰减**（日文圈常提乐器 transient）  
- 纯稳态谐波匹配易把持续期的强倍音当成新 note  
- 失真电吉他：非线性产生 **非整数次互调**，谐波模板假设破功（帖 1 的痛点）  

### 7. 感知与理论边界

- 帖 12–13：自然倍音列偏 **major 骨架**；小三和弦、扩展和弦不能靠「自然谐波」硬套  
- 帖 6：合唱/共鸣会制造 **谱面没有的 7/9 度听感** → 自动识别若只跟听感会 over-detect tension

## 四、实用流水线（综合）

```
音频
 → (可选) 音源分离
 → 频谱 / CQT / 常数 Q
 → multi-F0 候选（谐波 salience，非峰值排序）
 → 谐波剪枝：k·f 从属删除 + octave 修正
 → chroma / pitch class（合并八度）
 → 和弦词典 + 时序模型
 → 输出和弦标签（必要时再映射回 voicing）
```

**误判对照表**

| 现象 | 原因 | 对策方向 |
|------|------|----------|
| 多出一个八度上的音 | 2f 当独立音 | 谐波从属 / octave merge |
| 根音错一个五度 | 3f 强或五度溶合 | 模板权重 + 低音轨约束 |
| 多出 7/9 | 高次倍音 / 合唱 | 能量阈值 + 时序平滑 |
| 低音估错 | missing F0 或互调 | GCD/salience；失真用数据驱动模型 |
| 和弦「太 major」 | 自然谐波偏大三 | 不要只用谐波和声先验 |
