|---|---|---|

So the musician consensus is less “pick a %” and more: **AI tabs are a rough draft; ear is still the QA layer.** Unedited AI as final product is widely treated as garbage.

## Consensus map (what “usable” means)

```
Trust as final tab (zero edit)
  → bar is very high; simple clean material only
  → unlabeled AI flood = community failure mode

Usable as scaffold (edit by ear)
  → ~80% “shape is right” is often enough (JP explicit)
  → 50%/10% material-dependent scores = not worth it for hard stuff

Usable as reference for practice/band
  → “mostly right” / clean dry tracks / power-chord material
  → still expect bass/voicing/fret errors
```

**Closest thing to your “80% useless / 95% fine” frame on X:**

- **As finished notation:** community acts like **anything with frequent wrong notes is useless** (Songsterr AI backlash; “aren’t close”).
- **As a draft:** **~80% is explicitly OK** if you re-input/fix (**@blue_pine**).
- **As “I can stop listening”:** needs **near-100% on simple parts** claims only (**@YAMU_ViCTiM**), and even then only with clean audio.
- **Hard music as-is:** some users put A2M at **10–50%** and call **pre-MuScriptor A2M non-practical**.

## Caveats

1. **Almost nobody quotes academic note-F-measure** (onset/offset/pitch) on X; they use feel (“mostly right,” “rubbish,” “8割”).
2. **Songsterr dominates EN frustration**; JP mixes Songsterr + MuScriptor/Mirelo/local A2M.
3. **Clean mono/dry sources** get much kinder reviews than mixed YouTube masters.
4. The exact slogan **“80% useless / 95% fine”** is common for *speech/work AI* on X; for **music notes**, people describe the same idea via workflows and insults, not that phrase.
